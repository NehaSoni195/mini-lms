# Mini LMS App 📚

A modern React Native LMS (Learning Management System) mobile application built using Expo Router.
The app allows users to browse courses, bookmark courses, enroll in courses, view embedded course content through WebView, and manage their profile.

---

# ✨ Features

## Authentication

* User Registration
* User Login
* Form Validation
* Error Handling

---

## Home Screen

* Course listing
* Search functionality
* Pull to refresh
* Instructor integration
* Modern UI cards

---

## Course Details

* Course information
* Bookmark functionality
* Enrollment system
* Instructor details

---

## Embedded Content Viewer

* WebView integration
* Dynamic HTML content rendering
* Native → WebView communication
* LMS styled embedded content page

---

## Profile Screen

* User information
* Profile image upload
* Bookmark count
* Enrolled courses count

---

## Local Notifications

* Notification permission handling
* Bookmark milestone notifications
* 24-hour inactivity reminder system

---

# 🛠 Tech Stack

* React Native
* Expo
* Expo Router
